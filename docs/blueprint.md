# **App Name**: Adirya healthPro

## Core Features:

- Homepage Clone: Homepage Recreation: Duplicate the existing Adirya health homepage layout and content structure.
- Service Page Replication: Service Pages: Replicate the service pages offered on Adirya health (e.g., radiology, cardiology).
- Blog Clone: Blog Section: Create a blog section similar to the original site, with post listings and individual blog post views.
- Admin Panel: Admin Dashboard: Develop a CRM panel allowing administrators to manage website content.
- Page Management: Content Management: Allow admin to Add, edit, and delete website pages (homepage, service pages).
- Blog Post Management: Blog Management: Provide tools for administrators to create, edit, and delete blog posts, including rich text editing.
- AI Blog tool: Blog Post Assistant: An AI-powered tool to suggest blog topics based on trending healthcare searches and to check readability levels of the post before publication

## Style Guidelines:

- Primary color: Deep teal (#008080) to convey trust and reliability in healthcare.
- Background color: Light teal (#E0F8F7), almost white but still visibly the same hue.
- Accent color: Vibrant light green (#90EE90) for a clean and fresh feeling; will provide great contrast against the background and primary colors.
- Headline font: 'Poppins', sans-serif. 'Poppins' has a modern, precise feel, and it is very readable in short amounts of text. Body text: 'PT Sans', sans-serif. It blends modernity with approachability.
- Use a set of modern, line-based icons related to healthcare and medical services. Ensure consistency in style and weight.
- Implement a clean, responsive layout with clear sections and a focus on readability. Utilize whitespace effectively.
- Subtle animations and transitions can be used to enhance user experience and provide visual feedback without being distracting.
