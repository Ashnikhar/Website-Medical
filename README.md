## 🚀 Getting Started

To run this project locally, follow these steps:

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Installation

```bash
git clone https://github.com/Ashnikhar/Website-Medical.git
cd Website-Medical
npm install  # or yarn install
````

### Run Development Server

```bash
npm run dev  # or yarn dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## 📂 Folder Structure

```
/pages
  - index.tsx          → Home Page
  - about.tsx          → About Page
  - industries.tsx     → Industry Services
  - products.tsx       → Product Listing
  - success.tsx        → Success Stories
  - blog.tsx           → Blog Section
/components            → UI and layout components
/public                → Static assets
/styles                → Global and custom styles
```

## ✨ Customization

* Update brand colors or typography in `tailwind.config.js`
* Blog content and success stories can be dynamic or markdown-based
